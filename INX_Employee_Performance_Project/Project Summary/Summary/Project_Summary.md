# INX FutureInc. -Employee Performance Analysis

## 1. Project Overview

In this project, I worked on employee performance data from INX Future Inc. I analyzed department performance, found the main factors related to employee ratings, and built a machine learning model to predict performance ratings. Based on the results, I also suggested some ways to improve employee performance.

## 2. Key Findings

The analysis showed that employee performance was different across departments. Development had the highest average performance rating, while finance had the lowest. Salary Hike percentage, environment satisfaction, and years since the last promotion were among the important factors related to employee performance.

## 3. Model Results

I used a Random Forest Classifier to predict employee performance ratings. The model achieved 94.58% accuracy on the test data, with a weighted F1-score of 0.94. These results show that the model performed well on the test dataset.

## 4. Recommendations

From my analysis, I think the company should focus on employee satisfaction, salary hikes, and promotion opportunities. Regular feedback and proper recognition may help employee improve their performance. The company can also review the needs of different departments and provide support where needed.
